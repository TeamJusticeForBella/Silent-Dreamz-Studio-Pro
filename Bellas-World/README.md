## 🎵 What Is Bella's World?

Bella's World (formerly "Angelito's WRLD") is a complete AI-powered music creation ecosystem featuring:

- **ARCHANG3L-9** - Adaptive beat generation agent that learns your taste
- **Lyric Engine** - Soul x Strategy fusion for bars, hooks, and spoken word
- **Cadence Generator** - Flow algorithm that maps rhythmic phrasing

- **Agent Federation** - 6 specialized AI agents covering every creative need

## 🎯 Core Features

### 1. ARCHANG3L-9 - The Adaptive Sonic Architect

```
Role: Beat evolution agent
Learns: Your ear, loops, taste, reactions
Core Loop: Listen → Deconstruct → Reforge → Present → Learn
Memory: Stores tonal DNA, chord structure, swing, vinyl texture
Ethos: "Perfection is repetition refined by soul"
```

**Workflow:**
1. Drop a rare oldie (MP3/WAV)
2. ARCHANG3L-9 analyzes: tempo, key, groove, texture
3. Generates 10 variations
4. You tag which feels right
5. It evolves and learns your signature sound

### 2. Lyrics Engine

Generate bars, hooks, or spoken-word with emotional precision:

```bash
/write hook [theme: redemption | energy: cinematic victory | tone: prophetic]
/verse [style: drill x gospel | bpm: 140 | rhyme_density: 9/10]
/spokenword [voice: Father/General | tempo: 72 bpm | purpose: declaration]
```

**DNA Sources:**
- Heart Data (emotion-driven language)
- Tactical Syntax (flow patterns + assonance)
- Ancestral Memory (symbolic vocabulary + legacy tone)

### 3. Cadence Generator

Input tone/archetype → Get rhythmic phrasing maps synced to BPM grids:

```
🔊 Cadence Pattern: (8-bar loop @ 140 BPM)
Kick Alignment: 1 + 2e + 3 + 4a
Flow Type: "March of Prophets"
```

### 4. Beat Lab

Open-source sonic forge:
- Magenta.js for AI beat generation
- Tone.js for audio synthesis
- WaveSurfer.js for waveform visualization
- Export MIDI + WAV stems
